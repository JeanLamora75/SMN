# Créer une équipe

## Prérequis

Un administrateur autorisé doit avoir contrôlé les paramètres généraux.

## Étapes

- Ouvrez [Paramètres > Équipes](/app/admin/settings/teams).
- Utilisez le bouton de création d'équipe dans l'en-tête.
- Renseignez les champs affichés dans le formulaire, notamment le nom et le mode Agile si ce choix est proposé.
- Enregistrez puis vérifiez la présence de l'équipe dans la liste.
- Revenez dans la checklist pour déclarer **team** terminé lorsque l'équipe existe réellement.

## Scrum ou Kanban

Le mode de l'équipe détermine les écrans et fonctionnalités disponibles. Les sprints concernent Scrum ; les périodes Kanban concernent Kanban. Le guide ne crée aucune équipe à votre place.
