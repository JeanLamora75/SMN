# Votre équipe : partez de l'existant

Avant de suivre un sprint, prenez quelques minutes pour vérifier que SMN connaît bien votre équipe. Il n'est pas nécessaire de tout recréer : **commencez par regarder les équipes déjà présentes**.

Selon le type d'installation ou de restauration, des équipes peuvent déjà être disponibles. Sur une installation native v33 avec une base vierge, aucune équipe n'est créée automatiquement. Les modifications décrites ici nécessitent un compte administrateur.

## Une équipe existe déjà ? Personnalisez-la

1. Ouvrez [Paramètres > Équipes](/app/admin/settings/teams).
2. Retrouvez l'équipe concernée. Utilisez la recherche ou le filtre **Actives / Archivées** si besoin.
3. Sélectionnez l'équipe pour ouvrir sa fiche d'édition.
4. Adaptez son **nom**, son **produit**, sa **vision** et son **objectif** à votre contexte.
5. Vérifiez le mode **Scrum ou Kanban**. Il détermine les cycles proposés par SMN et peut ne plus être modifiable sur une équipe existante.
6. Enregistrez et contrôlez le résultat dans la liste.

> Une équipe existante est généralement une meilleure base qu'un doublon. Si le mode Agile ne peut pas être modifié, vérifiez la situation avant toute nouvelle création.

## Aucune équipe utilisable ? Créez-en une

1. Dans [Paramètres > Équipes](/app/admin/settings/teams), cliquez sur **Créer une équipe** dans l'en-tête.
2. Donnez-lui un nom facile à reconnaître et choisissez **Scrum** ou **Kanban**.
3. Complétez le produit, la vision et l'objectif avec les informations dont vous disposez.
4. Validez puis retrouvez votre nouvelle équipe dans la liste.

## Pourquoi ces informations comptent-elles ?

Le mode Agile donne accès aux **sprints** ou aux **périodes Kanban**. L'équipe sert ensuite de fil conducteur pour les membres, les cycles, les données de suivi et les rapports.

Vous pourrez compléter les informations progressivement : le plus important, à ce stade, est de choisir le bon contexte de travail.

## Votre point de contrôle

Le nom et le mode Agile sont corrects, les informations produit ont été vérifiées et vous n'avez pas créé de doublon. Vous pouvez alors passer aux membres de l'équipe.
