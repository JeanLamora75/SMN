# Rapports : consulter, créer et générer des documents

## Accès et périmètre

Ouvrez [Rapports](/app/reports) après connexion et sélectionnez l'équipe autorisée lorsque l'interface le propose. Les informations affichées dépendent du contexte d'équipe, du cycle et des droits de votre compte. La création de nouveaux rapports depuis l'en-tête est réservée à l'administrateur dans les conditions prévues par l'écran.

## Comprendre les quatre onglets

- **Rapports** : consultez les documents enregistrés. Utilisez la recherche, le filtre par sprint ou cycle et, si disponible, le filtre d'état, puis ouvrez un rapport avec son action de lecture.
- **Modèles** : parcourez les modèles Office disponibles. Le catalogue propose des modèles Word et PowerPoint détectés dans les répertoires de SMN.
- **Tags** : consultez la documentation des expressions utilisables dans les modèles Office. Le configurateur aide à construire et copier un tag adapté à sa famille (information simple, indicateur, tableau ou graphique).
- **Archives** : consultez les éléments archivés du contexte autorisé ; les filtres disponibles permettent notamment de rechercher ou de sélectionner un cycle.

Les quatre onglets ne sont pas quatre étapes obligatoires : choisissez celui qui correspond à votre besoin.

## Consulter un rapport existant

1. Dans l'onglet **Rapports**, sélectionnez le cycle concerné, ou laissez **Tous** pour voir les documents du périmètre courant.
2. Saisissez un terme de recherche si nécessaire, appliquez les filtres et examinez la liste.
3. Vérifiez le titre, le sprint ou cycle, le modèle, l'état et la date de mise à jour.
4. Ouvrez le document avec la commande de lecture. Si la liste est vide, vérifiez l'équipe et les filtres avant de conclure qu'aucun document n'existe.

## Créer un rapport depuis SMN

Si votre compte est administrateur et que la commande **Nouveau rapport** est disponible :

1. Ouvrez la modale de création depuis l'en-tête du Centre Rapports.
2. Choisissez un **sprint ou cycle** et un **modèle** disponibles.
3. Renseignez le **titre** et choisissez la **langue** française ou anglaise.
4. Validez **Créer**. La commande peut être désactivée si aucun cycle ou modèle admissible n'est disponible, ou si les informations demandées manquent.
5. Consultez le rapport créé dans la liste et contrôlez son contenu. La création ne garantit pas que chaque donnée du modèle soit renseignée.

## Générer un document Office à partir d'un modèle

Dans **Modèles**, après avoir choisi un modèle Word ou PowerPoint :

1. Sélectionnez le cycle proposé et renseignez le **nom de fichier**.
2. Choisissez la **langue** du document et, lorsqu'il est disponible, le **style des graphiques**.
3. Si le modèle exploite des données de tickets, sélectionnez les photographies demandées dans les champs proposés.
4. Utilisez **Générer** pour télécharger le document, ou **Enregistrer** pour le conserver dans le répertoire Rapports de SMN. Ces deux actions sont distinctes.
5. Si l'enregistrement signale un fichier existant, lisez la demande de confirmation avant tout écrasement. Contrôlez ensuite le document obtenu.

Le système peut refuser une génération si le modèle ou une source de données nécessaire est absent, si un tag est invalide ou si la sélection de tickets n'est pas admissible. Corrigez les champs ou le modèle avant de réessayer ; ne supposez pas qu'un champ vide vaut zéro.

## Préparer les tags des modèles

Dans l'onglet **Tags**, ouvrez le configurateur pour sélectionner une famille, puis les paramètres proposés. Le résultat généré peut être copié dans le modèle Office. Les tags de tableaux peuvent proposer un tri ; les graphiques disposent de types et styles compatibles avec les indicateurs sélectionnés. Vérifiez la disponibilité des données pour l'équipe avant d'utiliser un tag d'indicateur.

## Résultat et limites

La génération et la sauvegarde sont des actions métier distinctes de la lecture de l'aide. La checklist du Centre d'aide est déclarative : marquez **reports** terminé seulement après avoir contrôlé votre propre résultat. L'ouverture de ce guide ne produit aucun document.
