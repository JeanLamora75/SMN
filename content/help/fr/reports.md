# Découvrir les rapports

## Prérequis

Un compte connecté, une équipe accessible et des données de reporting sont nécessaires.

## Étapes

- Ouvrez [Rapports](/app/reports).
- Consultez les onglets et modèles proposés selon vos droits.
- Sélectionnez l'équipe et le cycle si l'écran le demande.
- Consultez les documents existants ; si vous êtes autorisé, utilisez les fonctions de création disponibles.
- Vérifiez le résultat avant de déclarer manuellement **reports** terminé.

## Important

La présence d'un modèle ne garantit pas que les données requises soient disponibles. L'aide ne génère aucun document à votre place.
