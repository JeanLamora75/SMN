# Catégories d'absence : configurez SMN avec méthode

Les catégories facilitent une saisie homogène des absences des membres. Elles donnent du sens aux données consultées dans les calendriers et les analyses de capacité.

> **Le conseil de Camille :** commencez par examiner l'existant et ne modifiez que ce qui répond à un besoin identifié.

## 1. Pourquoi ce paramètre est-il utile ?

Les catégories facilitent une saisie homogène des absences des membres. Elles donnent du sens aux données consultées dans les calendriers et les analyses de capacité. Une configuration cohérente permet ensuite de limiter les saisies répétitives et de fiabiliser l'exploitation des données.

## 2. Retrouvez l'écran de configuration

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Catégories d'absence** dans la famille correspondante.
3. Ouvrez l'[écran de réglage](/app/admin/absence-categories) lorsque votre rôle le permet.
4. Examinez les données déjà présentes avant de créer ou modifier une entrée.

## 3. Procédez étape par étape

1. Consultez les catégories existantes pour éviter de créer un doublon.
2. Cliquez sur Créer une catégorie lorsque l'action est autorisée.
3. Renseignez le nom et les autres informations proposées par le formulaire.
4. Enregistrez, puis vérifiez l'entrée dans la liste.
5. Ouvrez le calendrier d'un membre et contrôlez la catégorie disponible.

## 4. Comprenez les champs et leurs effets

La catégorie identifie la nature d'une absence ; les dates et les demi-journées renseignées sur l'absence déterminent la période touchée.

> **Que change l'enregistrement ?** Le réglage est réutilisable par le module concerné. Les données historiques et les documents déjà générés ne sont pas nécessairement modifiés rétroactivement.

## 5. Conseils et résolution de problèmes

Préférez des libellés compréhensibles de tous. Les catégories doivent faciliter les bilans sans dévoiler inutilement des informations personnelles.

Si l'action est absente, vérifiez votre rôle et le statut de disponibilité dans les Paramètres. Lisez les erreurs de validation avant de recommencer.

## Votre point de contrôle

Savez-vous expliquer **ce qui a été changé, pourquoi et sur quel écran vérifier le résultat** ? Vous avez alors une configuration prête à être utilisée.
