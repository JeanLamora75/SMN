# Paramètres des registres : configurez SMN avec méthode

Les paramètres des registres permettent d'organiser les faits marquants automatiques et les alertes d'échéance. Ils complètent les fiches de risques, obstacles et dépendances.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Les paramètres des registres permettent d'organiser les faits marquants automatiques et les alertes d'échéance. Ils complètent les fiches de risques, obstacles et dépendances. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Paramètres des registres** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/registries) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Registres.
2. Dans l'onglet Catégories, consultez les réglages des faits marquants automatiques.
3. Dans Alertes, vérifiez les règles de signalement des échéances.
4. Modifiez uniquement les options nécessaires, en tenant compte des droits.
5. Enregistrez puis contrôlez les alertes et registres affectés.

## 4. Comprenez les champs et leurs conséquences

Les alertes signalent des échéances ou situations à examiner ; elles ne résolvent pas automatiquement un risque ou un obstacle.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Définissez qui relit les alertes et à quel rythme. Une règle sans suivi opérationnel devient vite du bruit.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
