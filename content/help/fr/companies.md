# Entreprises : configurez SMN avec méthode

Les entreprises permettent de structurer les références de votre organisation. Une fiche identifiable évite les doublons et facilite le choix d'une entité dans les écrans qui l'utilisent.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Les entreprises permettent de structurer les références de votre organisation. Une fiche identifiable évite les doublons et facilite le choix d'une entité dans les écrans qui l'utilisent. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Entreprises** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/companies) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez le menu Entreprises et examinez la liste avant toute création.
2. Recherchez une société existante pour éviter les doublons.
3. Utilisez l'action de création pour renseigner les informations demandées par le formulaire.
4. Enregistrez puis vérifiez la nouvelle entrée ; utilisez l'action Modifier pour une correction.

## 4. Comprenez les champs et leurs conséquences

Le nom de l'entreprise sert d'identifiant lisible dans les listes. Vérifiez aussi les autres informations de la fiche avant d'enregistrer.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Ne supprimez pas une entreprise simplement parce que son nom a changé : corrigez d'abord la fiche existante.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
