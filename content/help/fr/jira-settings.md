# Paramètres Jira

La configuration Jira devient plus simple lorsqu'on avance dans l'ordre. Vérifiez chaque réglage avant de vous appuyer sur les échanges de données.

## Avant de commencer

La configuration Jira est réservée à l'administrateur. La page ne garantit pas à elle seule qu'une connexion externe soit accessible dans votre environnement.

## Étape par étape

- Ouvrez [Paramètres Jira](/app/admin/settings/jira).
- Examinez les champs et les valeurs proposés dans le formulaire.
- Renseignez uniquement les informations de configuration nécessaires et suivez les vérifications affichées.
- Enregistrez depuis le formulaire métier, puis contrôlez le résultat avant de considérer l'intégration comme configurée.

## Sécurité

Ne placez jamais de jeton, mot de passe ou information privée dans le contenu de l'aide ou dans des captures publiques. L'accès à la page ne doit pas être proposé à un compte non administrateur.
