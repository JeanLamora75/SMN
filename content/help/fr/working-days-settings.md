# Jours et horaires travaillés : configurez SMN avec méthode

Cette configuration précise les créneaux de travail et les règles de pause du contexte Scrum. Elle complète les calendriers personnels des membres.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Cette configuration précise les créneaux de travail et les règles de pause du contexte Scrum. Elle complète les calendriers personnels des membres. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Jours et horaires travaillés** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/working-days) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Jours travaillés dans le contexte Scrum.
2. Dans Créneaux, vérifiez l'équipe et les plages de travail proposées.
3. Adaptez les horaires et jours selon la pratique de l'équipe.
4. Dans Pause déjeuner, vérifiez la règle de pause disponible.
5. Enregistrez puis contrôlez le calendrier et la cohérence avec les horaires individuels.

## 4. Comprenez les champs et leurs conséquences

Les créneaux d'équipe décrivent un cadre commun ; les horaires d'un membre peuvent différer et doivent être renseignés dans sa fiche.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Ne remplacez pas une absence par une modification permanente des jours travaillés : utilisez le calendrier d'absences pour les exceptions ponctuelles.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
