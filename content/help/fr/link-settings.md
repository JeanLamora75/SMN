# Paramètres des liens : configurez SMN avec méthode

Ces paramètres administrent le catalogue de liens et ses catégories. Les liens sont ensuite consultables dans le module Liens et réutilisables dans les affichages ou rapports compatibles.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Ces paramètres administrent le catalogue de liens et ses catégories. Les liens sont ensuite consultables dans le module Liens et réutilisables dans les affichages ou rapports compatibles. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Paramètres des liens** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/links) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Liens.
2. Dans Inventaire, consultez les liens existants et repérez les ressources obsolètes.
3. Dans Catégories, créez ou modifiez les catégories proposées lors de l'ajout d'un lien.
4. Vérifiez les intitulés, les URL et la portée Équipe ou Transverse.
5. Enregistrez puis ouvrez le module Liens pour contrôler les filtres et la visibilité.

## 4. Comprenez les champs et leurs conséquences

La catégorie facilite le classement ; la portée détermine si une ressource concerne une équipe ou un usage transverse.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Une catégorie utile se reconnaît immédiatement. Évitez les dizaines de catégories quasi identiques.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
