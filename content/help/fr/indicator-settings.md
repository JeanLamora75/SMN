# Catalogue des indicateurs : configurez SMN avec méthode

Le catalogue définit les mesures utilisables par SMN. Un indicateur manuel reçoit une valeur saisie par cycle ; un indicateur calculé utilise une formule basée sur d'autres données.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Le catalogue définit les mesures utilisables par SMN. Un indicateur manuel reçoit une valeur saisie par cycle ; un indicateur calculé utilise une formule basée sur d'autres données. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Catalogue des indicateurs** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/indicators) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Indicateurs et consultez Catalogue.
2. Cliquez sur Créer et définissez le nom, le tag unique, le type, la description et l'unité.
3. Pour un indicateur calculé, renseignez une formule reconnue par le Guide des expressions.
4. Enregistrez, puis prévisualisez les impacts avant toute modification de formule existante.
5. Dans le module Indicateurs, sélectionnez les indicateurs pour chaque équipe et choisissez leurs affichages.

## 4. Comprenez les champs et leurs conséquences

Le tag identifie l'indicateur dans les formules et les modèles Office ; la description définit précisément la signification métier du chiffre.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Évitez de renommer un tag utilisé dans un modèle Word ou PowerPoint : SMN ne réécrit pas automatiquement les fichiers Office existants.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
