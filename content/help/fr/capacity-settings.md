# Paramètres de capacité : configurez SMN avec méthode

Le catalogue Paramètres affiche une entrée Capacité prévue, mais aucun écran dédié de configuration n'est actuellement relié à cette entrée. Les calculs de capacité disponibles s'appuient sur les informations des membres.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Le catalogue Paramètres affiche une entrée Capacité prévue, mais aucun écran dédié de configuration n'est actuellement relié à cette entrée. Les calculs de capacité disponibles s'appuient sur les informations des membres. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Paramètres de capacité** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Repérez Capacité dans le menu Paramètres et consultez son état de disponibilité.
2. Pour agir dès maintenant, ouvrez les fiches Membres.
3. Vérifiez les affectations, horaires, absences et pays des membres.
4. Consultez les indicateurs de capacité sur les cycles disponibles.

## 4. Comprenez les champs et leurs conséquences

La capacité en jours-homme dépend notamment des périodes d'affectation, des rôles, des demi-journées travaillées et des absences. Une entrée annoncée ne signifie pas qu'un formulaire de réglage existe déjà.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Ne cherchez pas à forcer une configuration indisponible : complétez d'abord les données des membres et contrôlez les résultats.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
