# Tickets

Le module Tickets permet de consulter les fonctionnalités liées aux photographies CSV de tickets.

## Accès

- Ouvrez la rubrique **Tickets** depuis la navigation principale.
- Consultez les actions disponibles selon les droits de votre compte.

Cette introduction ne remplace pas la documentation détaillée des imports CSV, qui sera rédigée à partir du fonctionnement livré.
