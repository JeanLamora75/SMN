# Modèles de cérémonies : configurez SMN avec méthode

Les modèles évitent de recréer manuellement chaque cérémonie Scrum. Ils fournissent les règles servant à proposer ou générer les occurrences liées aux sprints.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Les modèles évitent de recréer manuellement chaque cérémonie Scrum. Ils fournissent les règles servant à proposer ou générer les occurrences liées aux sprints. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Modèles de cérémonies** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/ceremonies) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Cérémonies pour une installation utilisant Scrum.
2. Consultez les modèles existants avant de cliquer sur Créer.
3. Renseignez le type, le nom et la planification proposée selon les champs visibles.
4. Vérifiez l'état actif du modèle et enregistrez.
5. Lors de la génération d'un sprint, vérifiez les cérémonies proposées dans l'aperçu, puis contrôlez le calendrier.

## 4. Comprenez les champs et leurs conséquences

Une règle de modèle détermine les futures occurrences proposées ; chaque réunion générée devient ensuite un événement métier consultable et modifiable selon les droits.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Modifier un modèle ne garantit pas la modification rétroactive des cérémonies déjà créées. Vérifiez toujours les sprints existants.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
