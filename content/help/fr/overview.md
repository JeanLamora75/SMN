# Première configuration de SMN

Ce guide accompagne la prise en main de Scrum Master Notebook après l'installation. La lecture d'un article ne modifie aucune donnée.

## Avant la connexion

- Installez SMN depuis sa distribution Windows et démarrez-le avec le lanceur fourni. Ouvrez l'adresse locale affichée par le lanceur.
- Suivez les écrans d'initialisation et de création du premier administrateur, si l'installation n'est pas encore configurée. Cette étape se déroule avant l'accès au Centre d'aide.
- Connectez-vous. Les réglages métier exigent les autorisations associées à votre compte.

## Première configuration après connexion

- **general** : contrôlez [Paramètres généraux](/app/admin/settings/general) avec un compte administrateur.
- **team** : créez une équipe dans [Paramètres > Équipes](/app/admin/settings/teams) si vous y êtes autorisé.
- **calendar** : contrôlez le [Calendrier d'équipe](/app/team-calendar) et les jours de travail applicables.
- **members** : vérifiez les membres et leurs affectations dans [Équipe / Membres](/app/admin/members).
- **cadence** : préparez les [Sprints](/app/admin/sprints) en Scrum, ou les [Périodes Kanban](/app/admin/kanban-periods) en Kanban. Choisissez la procédure correspondant à l'équipe.
- **tickets** : consultez [Tickets](/app/tickets) après avoir choisi une équipe et un cycle.
- **reports** : ouvrez [Rapports](/app/reports) une fois les données nécessaires disponibles.
- **backup** : examinez les sauvegardes depuis [Maintenance](/app/admin/settings/maintenance) si vous disposez des droits requis.

Ces liens renvoient à de vrais écrans. Certains restent interdits aux utilisateurs non habilités : la checklist filtre les étapes applicables selon vos droits et le mode Agile. N'utilisez pas une action administrative si elle ne vous est pas accessible.

## Suivre la checklist

Vous pouvez indiquer **À faire**, **En cours** ou **Terminé (déclaré)** pour chaque étape applicable. La lecture du guide ne coche jamais l'étape. Le compteur mesure vos déclarations, pas une validation automatique de SMN.

La progression reste uniquement dans le stockage du navigateur utilisé pour cette adresse SMN ; elle n'est pas transférée vers un autre ordinateur ni incluse dans les sauvegardes.

## Sauvegarde et restauration

Une archive de sauvegarde ne garantit pas qu'une restauration soit autorisée. Consultez l'état de vérification et les conditions de sécurité dans Maintenance avant toute opération.
