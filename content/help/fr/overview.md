# Première configuration de Scrum Master Notebook

Ce guide accompagne la première prise en main après l'installation et la connexion à SMN. Les réglages sont réalisés dans les écrans métier ; consulter un guide ne les modifie pas.

## Avant de commencer

- Lancez l'installation SMN fournie pour votre ordinateur et démarrez l'application locale avec son lanceur. Utilisez l'adresse affichée par le lanceur.
- Terminez l'initialisation et la création du premier compte administrateur en suivant les écrans proposés par l'application. Ces opérations se déroulent avant la connexion et ne sont pas pilotées par le Centre d'aide.
- Connectez-vous avec un compte autorisé. Un utilisateur sans droits administrateur peut consulter les rubriques autorisées, mais ne peut pas effectuer toutes les étapes de configuration.

## Parcours recommandé après connexion

- **Paramètres généraux** : l'administrateur ouvre Paramètres puis Paramètres généraux, et vérifie les choix proposés.
- **Équipe** : dans Paramètres puis Équipes, l'administrateur utilise le bouton de création et choisit le mode Agile approprié.
- **Calendrier** : consultez le calendrier de l'équipe pour vérifier jours et absences. Certaines règles de jours travaillés sont accessibles dans les Paramètres selon le mode Scrum et les droits.
- **Membres** : dans Équipe / Membres, vérifiez les profils et les affectations.
- **Cycles** : en Scrum, ouvrez Sprints ; en Kanban, configurez les périodes Kanban. Ne suivez pas une procédure Scrum sur une équipe Kanban.
- **Tickets** : ouvrez Tickets après avoir sélectionné une équipe et un cycle, et consultez les données ou les possibilités d'import autorisées.
- **Rapports** : ouvrez Rapports lorsque les données nécessaires sont disponibles.
- **Sauvegarde** : dans Paramètres puis Maintenance, repérez la fonction de sauvegarde et ses vérifications. Une sauvegarde ne garantit pas à elle seule qu'une restauration soit autorisée.

## Suivre les étapes sans modifier les données

La checklist « Première configuration » du Centre d'aide indique les étapes applicables à votre rôle et à votre mode Scrum/Kanban. Vous choisissez manuellement **À faire**, **En cours** ou **Terminé (déclaré)**. Une visite de page ne termine pas une étape.

Cette progression est conservée uniquement dans le stockage de ce navigateur et de cette adresse SMN : elle n'est pas incluse dans les sauvegardes SMN et ne suit pas votre compte sur un autre ordinateur.

## En cas de difficulté

Si un écran ou une action est absent, vérifiez vos droits, l'équipe sélectionnée et son mode Agile. N'interprétez pas une absence comme une configuration déjà effectuée. Les guides spécialisés sont proposés lorsque leur contenu est disponible et que votre compte a les droits correspondants.
