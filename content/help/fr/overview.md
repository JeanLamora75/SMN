# Bien démarrer avec SMN

Scrum Master Notebook permet de suivre les équipes et leurs activités Agile.

## Première utilisation

- Consultez les paramètres de votre installation.
- Sélectionnez une équipe à laquelle vous avez accès.
- Utilisez les rubriques de navigation pour découvrir les fonctionnalités disponibles.

Cette présentation générale ne valide aucune étape de configuration. Le guide détaillé de première installation sera fourni séparément.
