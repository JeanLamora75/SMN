# Vérifier les paramètres généraux

## Prérequis

Vous devez avoir accès aux paramètres. Leur modification nécessite les droits correspondants, généralement administrateur.

## Étapes

- Ouvrez [Paramètres généraux](/app/admin/settings/general).
- Examinez les champs et les réglages effectivement proposés par le formulaire.
- Ajustez les paramètres nécessaires puis utilisez l'action d'enregistrement de l'écran.
- Vérifiez le résultat affiché et, si besoin, rechargez la page pour contrôler les valeurs.
- Marquez manuellement l'étape **general** terminée dans le Centre d'aide.

## Résultat

Les paramètres souhaités sont enregistrés par l'écran métier, jamais par le Centre d'aide. Un utilisateur sans permission ne doit pas tenter de modifier la configuration.
