# Préparer le premier sprint Scrum

## Prérequis

Vous devez avoir accès à une équipe Scrum. Les opérations de création exigent les droits appropriés. Ce guide ne s'applique pas au mode Kanban.

## Étapes

- Ouvrez [Sprints](/app/admin/sprints).
- Sélectionnez l'équipe Scrum concernée.
- Examinez les sprints existants ou, si vous êtes administrateur, utilisez l'action de génération proposée.
- Vérifiez la cadence, les dates et les statuts avant de confirmer une opération métier.
- Contrôlez le sprint dans la liste après l'opération, puis déclarez manuellement **cadence** terminé.

## Attention

SMN peut rediriger vers l'accueil si le mode Scrum ou les droits nécessaires ne sont pas réunis. Aucun sprint n'est généré par le Centre d'aide.
