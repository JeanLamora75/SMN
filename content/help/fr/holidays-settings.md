# Pays et jours fériés : configurez SMN avec méthode

Les jours fériés nationaux sont associés au pays de localisation du membre. Cette rubrique permet d'examiner les références de pays qui servent au calendrier.

> **Le conseil de Camille :** avant de modifier un paramètre, prenez le temps de comprendre sa portée. Un bon réglage est celui dont vous savez expliquer l'effet à l'équipe.

## 1. À quoi sert cette rubrique ?

Les jours fériés nationaux sont associés au pays de localisation du membre. Cette rubrique permet d'examiner les références de pays qui servent au calendrier. La consulter est particulièrement utile lorsque l'organisation évolue ou lorsque le résultat d'une fonctionnalité ne correspond pas à ce que vous attendiez.

## 2. Retrouvez le bon écran

1. Ouvrez les [Paramètres](/app/admin/settings).
2. Repérez **Pays et jours fériés** dans les familles de configuration.
3. Ouvrez la rubrique lorsqu'elle est disponible ; son [écran de configuration](/app/admin/settings/holidays-closures#holidays) est également accessible par ce lien.
4. Vérifiez les **droits**, le **contexte d'équipe** et les valeurs déjà enregistrées.

## 3. Suivez les étapes de configuration

1. Ouvrez Paramètres puis Jours fériés.
2. Consultez l'onglet Pays / jours fériés.
3. Vérifiez les pays disponibles et les informations affichées.
4. Dans la fiche d'un membre, contrôlez son code pays ISO à deux lettres.
5. Revenez à son calendrier pour vérifier les jours fériés attendus.

## 4. Comprenez les champs et leurs conséquences

SMN recherche les jours fériés correspondant au pays de chaque membre ; les fêtes locales ne sont pas forcément couvertes.

> **Que se passe-t-il après Enregistrer ?** La configuration devient disponible pour les modules concernés. Cela ne signifie pas que toutes les données historiques, réunions déjà générées ou rapports déjà produits seront automatiquement modifiés.

## 5. Conseils pratiques

Si un jour férié semble absent, vérifiez d'abord la localisation du membre et le référentiel du pays avant de saisir une absence.

**Si l'option est indisponible**, contrôlez les droits de votre compte, le mode Scrum ou Kanban et le statut de la rubrique dans les Paramètres. Une fonction annoncée comme « prévue » n'est pas encore un formulaire opérationnel.

## Votre point de contrôle

Pouvez-vous expliquer **ce qui a changé, pourquoi, à quoi cela sert et comment vérifier l'effet du réglage sur l'écran métier concerné** ? Si oui, votre configuration est prête à être utilisée.
