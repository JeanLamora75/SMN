# Prepare Kanban periods

## Prerequisites

You need access to a Kanban team. Managing periods requires the appropriate permissions.

## Steps

- Open [Kanban periods](/app/admin/kanban-periods).
- Review existing periods and the selected team context.
- If authorized, use the period-creation form.
- Verify displayed details and dates after saving.
- Manually mark **cadence** done once the periods are ready.

## Scrum and Kanban

A Kanban period is not a Scrum sprint. Help does not create any period.
