# Reports: view, create and generate documents

A good report tells the story of what happened and helps decide what comes next. Learn to turn SMN data into useful documents without losing sight of the sources.

## Access and scope

Open [Reports](/app/reports) after signing in and select an authorized team when the screen provides that option. Results depend on the team, sprint or cycle and your account permissions. Creating a new report from the header is restricted to administrators when the screen allows it.

## Understand the four tabs

- **Reports**: browse saved documents. Use search, sprint or cycle filters and any available status filter, then open a report with the read action.
- **Templates**: browse available Office templates. The catalog detects Word and PowerPoint templates in SMN's configured folders.
- **Tags**: read the available Office expressions. The tag configurator helps you build and copy a tag for a simple value, indicator, row or chart.
- **Archives**: browse archived items within your authorized context; available filters include searching and cycle selection.

The four tabs are separate workflows, not mandatory steps.

## Read an existing report

1. On **Reports**, choose the relevant cycle or leave **All** to browse the current scope.
2. Enter a search phrase if needed, apply filters and review the results.
3. Check the title, sprint or cycle, model, status and update date.
4. Open the document using its read action. If nothing appears, check the team and filters first.

## Create a report in SMN

If you are an administrator and **New report** is available:

1. Open the creation dialog from the Report center header.
2. Choose an available **sprint or cycle** and **template**.
3. Enter the **title** and choose **French** or **English**.
4. Select **Create**. The action may be disabled when no suitable cycle or template exists or a required field is missing.
5. Find the new report in the list and review its content. Creating it does not guarantee that all model data is available.

## Generate an Office document from a template

On **Templates**, after selecting a Word or PowerPoint model:

1. Select the cycle offered by the form and enter a **filename**.
2. Choose the document **language** and, when available, a **chart style**.
3. If the template uses ticket data, select the ticket snapshots required by the form.
4. Choose **Generate** to download a file, or **Save** to place it in SMN's Reports folder. These are separate actions.
5. If saving detects an existing file, review the overwrite confirmation before proceeding. Inspect the generated document afterward.

Generation may fail when a model or data source is unavailable, a tag is invalid or the ticket selection is unsuitable. Fix the fields or template before trying again; do not treat missing data as zero.

## Build template tags

On **Tags**, open the configurator and choose a family and its available options. Copy the generated expression into your Office template. Table tags may support sorting; chart tags offer compatible chart types and styles for the selected indicators. Check team data availability before using indicator tags.

## Result and limitations

Generating and saving reports are business operations, separate from reading Help. Help center progress is self-declared: mark **reports** done only after checking your own output. Opening this guide never generates a document.
